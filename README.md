# くらべるガレージ

2台の車を同じ縮尺で重ね、全長・全幅・全高の違いを直感的に比較できるWebツールです。

## 主な機能

- 2車種の全長・全幅・全高を比較
- 側面・正面・上面を同一縮尺で表示
- 後端・中央・前端基準の位置合わせ
- 車両Bの透過度調整
- 選択状態をブラウザー内に保存

## ローカル実行

Node.js 22以上とpnpmを使用します。

```bash
pnpm install
pnpm run dev
```

本番用の静的ファイルは次で生成します。

```bash
pnpm run build
```

## データと画像について

- 寸法は代表的な公表値を参考にした比較用データです。年式・グレード・仕様により異なります。
- 車両画像は縮尺比較用の生成画像で、実車写真ではありません。
- 本プロジェクトは各自動車メーカーとは関係ありません。車名・商標はそれぞれの権利者に帰属します。
